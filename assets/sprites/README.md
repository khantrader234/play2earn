# Sprite Assets

This directory contains the sprite assets for the runner game. Here are the required sprites:

1. Player Sprites:
- `player.png` (50x50 pixels)
  - A simple character sprite facing right
  - Recommended colors: Blue and white

2. Obstacle Sprites:
- `obstacle_ground.png` (30x50 pixels)
  - A ground-based obstacle (e.g., rock or cactus)
  - Recommended colors: Brown and gray
- `obstacle_flying.png` (30x50 pixels)
  - A flying obstacle (e.g., bird or cloud)
  - Recommended colors: White and gray
- `obstacle_jumping.png` (30x50 pixels)
  - A jumping obstacle (e.g., bouncing ball)
  - Recommended colors: Red and yellow

3. Power-up Sprites:
- `powerup_invincible.png` (30x30 pixels)
  - Invincibility power-up
  - Recommended colors: Blue and white
  - Star or shield shape
- `powerup_multiplier.png` (30x30 pixels)
  - Score multiplier power-up
  - Recommended colors: Green and yellow
  - "x2" symbol or star shape

4. Background Sprites:
- `backgrounds/sky.png` (800x600 pixels)
  - Blue gradient sky
- `backgrounds/mountains.png` (800x600 pixels)
  - Mountain silhouette
- `backgrounds/ground.png` (800x600 pixels)
  - Ground texture

5. Sound Effects:
- `sounds/jump.mp3`
  - Short jump sound effect
- `sounds/powerup.mp3`
  - Power-up collection sound
- `sounds/game_over.mp3`
  - Game over sound effect

Note: All sprites should be in PNG format with transparent backgrounds.
