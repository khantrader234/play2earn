2. breathing_stressed.mp3
3. breathing_breakdown.mp3
4. meeting_ambience.mp3
5. tear_drop.mp3
6. glitch_effect.mp3
7. achievement_unlocked.mp3
8. special_event.mp3
9. work_complete.mp3
10. therapy_session.mp3
11. microtransaction.mp3
12. background_music.mp3

Note: These files should be in MP3 format and properly licensed for use in the game.

You can use royalty-free sound effects from websites like:
- freesound.org
- zapsplat.com
- soundbible.com

Please ensure all sound files are:
- High quality (at least 128kbps)
- Properly trimmed
- Volume normalized

# Sound Effects

This directory contains the sound effects for the runner game. Here are the required sounds:

1. `jump.mp3`
   - A short, bouncy sound effect
   - Duration: ~0.2 seconds
   - Recommended: A light "boing" or "jump" sound

2. `powerup.mp3`
   - A bright, positive sound effect
   - Duration: ~0.5 seconds
   - Recommended: A "ding" or "chime" sound

3. `game_over.mp3`
   - A negative, game-ending sound effect
   - Duration: ~1 second
   - Recommended: A "buzz" or "fail" sound

Note: All sounds should be in MP3 format and kept as short as possible to maintain game performance.
